# data/original

The three class folders from the Kaggle dataset, unchanged:

```
Tomato___healthy/        (1,273 images)
Tomato___Early_blight/   (800 images)
Tomato___Late_blight/    (1,527 images)
```

Source: https://www.kaggle.com/datasets/charuchaudhry/plantvillage-tomato-leaf-dataset (folder `plantvillage/`).
`tomato_original.zip` in this folder holds exactly these three folders; notebook Cell 1.0 unzips it here,
so Colab needs no upload or Kaggle account. To rebuild from Kaggle instead, copy the three folders here.
